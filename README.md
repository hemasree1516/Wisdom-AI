# Wisdom AI

**Ontology is the Study of Being**
**Wisdom is the Art of Being Well**

Wisdom AI is an intelligent guidance web application that combines modern Artificial Intelligence with timeless wisdom from trusted knowledge sources such as the Bhagavad Gita, Ramayana, Mahabharata, Mahatma Gandhi, Dr. A.P.J. Abdul Kalam, and Swami Vivekananda.

The system helps users facing stress, confusion, fear, or important life decisions by providing meaningful, explainable, and personalized guidance.

---

# Features

* User input with age, gender, and problem statement
* Knowledge source selection
* AI-generated personalized guidance
* Explainable reasoning flow:

  * Emotion
  * Conflict
  * Guiding Principle
  * Outcome
* Story-based explanation
* Actionable wisdom suggestions
* Responsive design for mobile and desktop
* Modern UI

# Installation

## 1. Clone the Repository

```bash
git clone https://github.com/your-username/wisdom-ai.git
cd wisdom-ai
```

## 2. Install Dependencies

```bash
npm install
```

## 3. Run the Project

```bash
npm start
```

The app will run at:

```bash
http://localhost:3000
```

---

# Build for Production

```bash
npm run build
```
